=====================================================
GANYMEDE FILE SERVER - HOST INSTALLATION MANUAL
=====================================================

OVERVIEW
--------
Ganymede is a simple file sharing server that allows you to share files from
your computer with others over the internet. It creates a secure, password-
protected website that others can access to download files you place in a
specific folder.

FEATURES
--------
• File sharing with password protection
• Folder browsing and downloading as zip archives
• Download progress tracking for both files and folders
• File search functionality
• Thumbnails for image files
• User-specific background images
• Customizable greetings

PREREQUISITES
------------
1. Node.js (v14 or newer) - Download from https://nodejs.org/
2. A computer that can remain powered on while sharing files
3. Basic knowledge of command line/terminal usage

INSTALLATION
-----------
1. Open a command prompt/terminal and navigate to the folder where you want 
to install Ganymede.

2. Clone the Ganymede repository from GitHub:
    git clone https://github.com/maharava/ganymede.git

3. Navigate into the cloned repository:
    cd ganymede

4. Open a command prompt/terminal in this folder and run:
   npm install

   This will install all required dependencies.

CONFIGURATION
------------
Create or edit the .env file with a text editor and configure:

1. PORT (optional, default is 3000):
   PORT=3000

2. USER CREDENTIALS (username:password format, comma-separated):
   USER_CREDENTIALS=username1:password1,username2:password2

   Example:
   USER_CREDENTIALS=kyle:kaiyabi,reece:karo

3. GREETING MESSAGES (optional):
   GREETING_HEADER=Hi, {username}! I'm Ganymede
   GREETING_SUBHEADER=Want some of my files? Yeah you do:
   GREETING_EMPTY=I got nothing! Tell whoever owns me to put files in the "shared_files" directory.

   Note: {username} will be replaced with the logged-in user's name.

CUSTOMIZING THE APPEARANCE
-------------------------
1. The "assets" folder is included in the Ganymede repository and contains 
default assets.

2. To customize the appearance, replace the following files in the "assets" 
folder:
    - Background images (1920x1080px recommended):
      - For all users: assets/background.png
      - For specific users: assets/background_username.png
         (Example: assets/background_kyle.png for user "kyle")

    - Favicon (optional):
      - assets/ganymede.ico

SHARING FILES
------------
1. Open the "shared_files" folder in your Ganymede directory

2. Place any files or folders you want to share in this folder
   - These will be available to anyone with login credentials
   - You can create subfolders to organize your files
   - Users can navigate through folders and download entire folders as zip archives

FILE ORGANIZATION
---------------
Ganymede now supports folder hierarchies:
- Create folders inside the "shared_files" directory to organize your content
- Users can browse through these folders in the web interface
- Folders can be downloaded as zip archives with a single click
- Image files will show thumbnails for easy identification

RUNNING THE SERVER
-----------------
1. On Windows: Double-click start-ganymede.bat
   On Mac/Linux: Run "node ganymede.js" in terminal

2. The server will display:
   - Your local address (http://localhost:3000)
   - Your public IP address
   - A tunnel URL (https://something.loca.lt)

3. IMPORTANT: The tunnel URL is how others will access your files.
   Make note of this URL to share with your users.

4. If you see "Address already in use" errors:
   - Either change the PORT in your .env file (e.g., PORT=3001)
   - Or close any other applications using port 3000
   - Or restart your computer to free up the port

SHARING ACCESS WITH USERS
------------------------
To allow users to access your file server:

1. Share with them:
   - The tunnel URL (displayed when you start the server)
   - Their username and password (that you configured in .env)
   - Your public IP address (they'll need this as a tunnel password)

2. When they access the URL, they will:
   - First be prompted for the tunnel password (your public IP)
   - Then be prompted for their Ganymede username/password

USER INTERFACE FEATURES
---------------------
When users access Ganymede, they can:

1. BROWSE FILES:
   - Navigate through folders by clicking on folder names
   - Return to parent folders with the "Back to root" or parent directory links

2. SEARCH FILES:
   - Use the search box at the top of the page to find files by name or type
   - Search results update instantly as you type
   - Matching text is highlighted in search results

3. DOWNLOAD FILES:
   - Single files: Click on a file name to download it
   - Multiple files: Use the "Download All Files" button
   - Entire folders: Click the "Download Folder" button next to a folder

4. TRACK DOWNLOADS:
   - A progress overlay appears for all downloads
   - Shows real-time progress with percentage and file size information
   - Progress bars indicate download status
   - Download completion is confirmed with a notification

5. SWITCH BACKGROUNDS:
   - If user-specific backgrounds are configured, users can toggle between
     default and personal backgrounds using the icon in the top-right corner

SECURITY NOTE
------------
- Anyone with the tunnel URL, your public IP, and valid credentials can 
access your shared files
- Only share credentials with people you trust
- The server is only active while running on your computer
- Files are served directly from your computer's storage
- It's recommended to close Ganymede when not in use

TROUBLESHOOTING
--------------
1. "Cannot find module" errors:
   - Run "npm install" again in the Ganymede directory

2. "Address already in use" errors:
   - Change the PORT in your .env file
   - Close any applications that might be using port 3000
   - Run this command to find the process using the port:
     Windows: netstat -ano | findstr :3000
     Then kill that process: taskkill /F /PID <PID>

3. Tunnel connection issues:
   - Restart the server
   - Check your internet connection
   - Your firewall might be blocking the connection

4. Files not visible:
   - Make sure they're in the "shared_files" directory
   - Reload the page
   - File names with special characters might cause issues

5. Download progress not showing:
   - Make sure JavaScript is enabled in the browser
   - Try a different browser (Chrome or Firefox recommended)

6. Folders not downloading:
   - Check if the archiver module is installed (npm install archiver)
   - Make sure the folder doesn't contain special characters in the name

TECHNICAL INFORMATION
-------------------
Ganymede uses the following technologies:
- Node.js and Express for the web server
- Socket.IO for real-time download progress
- Archiver for creating zip archives of folders
- EJS for HTML templating
- LocalTunnel for internet accessibility

For developers who want to modify Ganymede, the main files are:
- ganymede.js: The main server file
- views/index.ejs: The front-end template
- .env: Configuration file
